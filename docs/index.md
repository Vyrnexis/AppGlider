# AppGlider documentation

AppGlider keeps your AppImage apps in one place. It downloads them from their GitHub pages, checks that each download arrived intact, adds them to your application menu and tells you when a new version is out.

New to AppGlider? Start with [Install AppGlider](get-started/install.md), then [add your first app](get-started/first-app.md).
